# Payora Frontend

Responsive mobile-first web frontend for Payora digital wallet.

## Tech Stack
- React 18 + Vite
- React Router DOM
- TanStack Query (React Query)
- Lucide React Icons

## Features
- Balance view and quick actions
- Send money, Add money (Top-up), Merchant payment, Cash-out
- Transaction history with receipt modal
- Saved payees, statement downloads, and admin operations
